This is `paw`, a fork of [foot](https://ci.codeberg.org/dnkl/foot) that adds kitty image protocol support. The work was done by AI agents from China.

## Kitty graphics size

Kitty graphics support adds about 6,530 lines of C. The full tree holds about 62,100 lines of C. This is about 10.5%. Counts include code only. They exclude docs and tests.
